# Resultados dos testes de carga

Cada execução do k6 grava aqui dois arquivos com o nome do cenário e o instante da execução:

- `.txt`: o resumo legível (o mesmo impresso no terminal), com os *thresholds* aprovados ou reprovados;
- `.json`: o resumo completo, com todas as métricas.

Eles ficam versionados como evidência do RNF02–RNF04. Como executar: [`../README.md`](../README.md).
